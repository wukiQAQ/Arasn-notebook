# 0.6.0 核心验收与基准

日期：2026-11-02。环境：当前 Windows x64 开发机，Node 24.14、锁定的 Electron 45；不是跨机器或长期运行的性能结论。

| 检查 | 结果 | 范围 |

## 基准（当前机器，单次样本）

| 项目 | 测量 | 限制 |
| --- | --- | --- |
| SQLite Worker 初始化 | 35.4 ms | 新建小数据库；不含大规模首次 JSON 迁移 |
| 128 MiB 文件导入 | 304 ms | 本地缓存/稀疏测试文件，不能视为实际硬盘持续吞吐 |
| 上述导入期间 Node 主事件循环额外延迟最大值 | 6.1 ms | 10 ms 采样探针，主循环保持运行 |
| 打包程序启动至文件页可交互 | 763 ms | 一次本机启动，含自动点击文件页，不是冷启动 P95 |
| 原生 showInactive/hide 调用，30次 P95 | 4.50 ms | 不包含键盘分发、焦点切换或最终画面完成 |
| Electron 各进程工作集求和快照 | 约381 MiB | 可能重复计算共享页，不是精确私有内存/PSS |

测试内 CPU 快照为0，不能据此宣称长期空闲 CPU 为0。Electron 内存和包体仍偏大，轻量化目标没有完成；本轮首先消除了主线程大文件复制、核心同步文件写盘以及无意义的本机白板轮询。

## 界面检查

采用现有文具工作台设计与语义色，不另建一套视觉系统。比较独立整页、弹窗与现有面板文件页后选择第三种，主任务为“导入、查找、引用、恢复”，优先级高于装饰。

实际捕获并检查 1440、520、390px 三种宽度。第一轮后修正主操作不突出、文件大小误显示0.00MiB、控件偏小；第二轮后修正列表与分页重叠、内部UUID名称过长、白色缩略图缺少边界。最终截图已再次捕获检查：

## 明确未验收与使用边界

- 真实全局按键至画面完成的延迟、中文输入法/多屏和长期资源占用仍需现场测量。
- 未进行真实系统断电、磁盘满、硬盘故障或百万文件目录测试。
- 缩略图仅安全识别的 PNG/JPEG；其他格式只存储/导出，不自动执行或预览。
- 文件仅在本机中转站与面板引用视图中管理，不通过 LAN 文件传输；现有 LAN 继续共享文字和笔迹。
- 文件面板引用在“文件 → 面板文件”查看，尚不是绘图画布上可拖动的附件卡片。
- 默认不自动删除备份或按周期清理；清空回收站前有完整备份。删除程序目录前应保留应用 userData。

## 运行

```powershell
npm test
node tests/core-desktop.cjs --packaged
node tests/settings-smoke.cjs
node tests/performance.cjs
npm run pack:versioned
```

测试使用独立临时数据目录。系统剪贴板测试在完成后恢复原条目；不会持续监听剪贴板。运行集成测试前避免另一个测试实例使用同一测试快捷键。
