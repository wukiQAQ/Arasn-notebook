# MVP 开发与验收清单

目标版本：0.1.0。当前仅交付设计文档，以下开发项均未完成。
设计依据：[MVP-DESIGN.md](MVP-DESIGN.md)。不按未经验证的工期估算承诺上线日期。

## M0：验证桌面能力

- [ ] 初始化 Tauri 2 + React + TypeScript，锁定依赖，记录开发环境。
- [ ] 在 Windows 11 x64 验证 WebView2 与干净机器安装流程。
- [ ] 验证托盘、单实例、快捷键注册/冲突/更改、显示隐藏与焦点。
- [ ] 验证中文输入法组合输入、Ctrl+Enter、Esc、多屏和缩放。
- [ ] 验证 Canvas 输出及 Windows 图片剪贴板；不通过则先解决原生能力。

出口：应用能稳定呼出、输入和隐藏；记录 P95 呼出时间，决定是否继续当前容器。

## M1：本地使用闭环

- [ ] 创建 SQLite 迁移与账号/guest 数据隔离。
- [ ] 实现纯文本与画布编辑、撤销重做、内容大小校验。
- [ ] 实现草稿防抖保存、隐藏刷盘、异常恢复。
- [ ] 实现卡片冻结、PNG 原子落盘、SQLite 发送事务与持久化 outbox。
- [ ] 实现列表、查看、复制文字、复制/保存图片、再次编辑为新草稿。
- [ ] 覆盖磁盘写入失败、保存中退出、未引用文件恢复。

出口：断网、退出、重新打开后，已保存草稿与待发送卡片仍在。

## M2：云端与身份

- [ ] 创建独立 Supabase 项目，配置邮箱验证码与会话刷新。
- [ ] 提交可重复执行的云端迁移：cards、约束、索引、RLS、软删除函数。
- [ ] 创建私有图片 bucket、大小限制和用户路径权限。
- [ ] 用两个真实测试账号验证跨账号读写删除、伪造路径、未登录访问均被拒绝。
- [ ] 使用 Windows Credential Manager 保存刷新令牌，禁止前端获取管理密钥。
- [ ] 覆盖退出和切换账号的在途请求、命名空间与队列隔离。

出口：通过账号隔离测试后，才接入真实用户内容。

## M3：两机互通

- [ ] 实现图片先上传、卡片后插入、重复请求摘要核对与确认状态。
- [ ] 实现队列重试、重启恢复、401 刷新、限流退避和永久错误展示。
- [ ] 实现全量元数据分页扫描、图片延迟加载、打开/后台/唤醒调度。
- [ ] 实现软删除与图片清理重试、同卡片操作串行、删除不复活；覆盖删除后晚到的旧扫描响应。
- [ ] 在两台电脑验证文字、手绘、组合卡片、双向发送与复制。
- [ ] 覆盖上传后断网、响应丢失、重复点击、分页中插入和离线 20 卡片恢复。

出口：两机完成主流程，无丢失、重复、账号串用；按设计第 8 节记录延迟。

## M4：内部试用包

- [ ] 构建可安装的 Windows x64 内部试用包，在干净机器验证。
- [ ] 检查日志、安装包和 Git 历史无凭据或私人数据。
- [ ] 补充实际安装说明、配置说明、测试记录和已知问题。
- [ ] 执行设计第 8 节全部验收，记录通过项、失败项和测试条件。
- [ ] 打包版本与源码提交一致；正式公开发布前配置签名并单独确认发布范围。

出口：可安装的内部 MVP，用户能够在两台自己的电脑完成记录和传递。
