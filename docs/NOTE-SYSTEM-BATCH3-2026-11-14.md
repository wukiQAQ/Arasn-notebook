# 属性面板与画笔预设 · 第三批

沿用 Graphite 与工具栏旁的紧凑属性浮层，无新增依赖、数据迁移或 EXE 打包。

## 实现

- 选择：选中对象才显示位置、尺寸和对应样式；笔迹、文字、附件各显示自己的属性。对象样式编辑不覆盖下一笔的默认参数。
- 手掌：只显示视口导航说明；橡皮擦只显示原笔迹级范围；文字显示色板、HSL、字号和加粗；画笔/图形显示颜色、粗细与实际笔刷参数。
- 六色快捷色板、自定义颜色、HSL、10%–100%透明度、四档粗细、圆/平/方端点、原始点列邻点加权平滑。
- 细笔、记号笔、虚线笔三套内置完整方案。记号笔由12px宽线、35%透明度、方头组成；虚线按线宽生成间隔。没有声称支持压力或软边。
- 自定义方案最多12套，名称最长32字；保存、应用和删除。桌面走既有原子设置持久化，校验结构、枚举、范围和未知字段；浏览器使用localStorage，损坏数据忽略，写入失败明确提示。桌面保存/删除/重启/拒绝非法配置及失败不假保存已验；浏览器存储故障未独立跑真实浏览器专项。
- StrokeValue新增可选brush/lineCap/smoothing；旧笔迹缺省维持实线、圆端点、无平滑、不透明。SVG/PNG共用路径和平滑/虚线参数，命中与整条擦除使用平滑点列。
- 修复历史冲突判断依赖JSON字段顺序：服务端返回相同内容但顺序改变时允许撤销；真正的外部修改仍拒绝覆盖。新增回归先复现失败，再验证修复。

## 验收中发现的事项与边界

- 首次测试在界面乐观笔迹出现后立即读服务端，保存尚未完成；改为等待服务端笔迹数，未削弱持久化断言。
- 新参数触发历史字段顺序误判，已由失败单测与真实Electron撤销测试定位并修复；不是输入丢失根因修复。
- 两次中间专项在故障注入后未恢复设置IPC，功能已输出PASS但隔离进程未正常结束；按本轮测试PID核实并终止其进程树。测试已恢复原处理器并加入finally保护，最终完整运行正常退出。不据中间PASS声称清理成功。
- 沙箱内临时文件原子改名EPERM；真实存储/Electron验收在沙箱外的隔离临时目录运行。没有操作用户个人库。
- 没有重跑Win32原生前台/置顶、物理键鼠/触控笔、混合DPI、长稳、关系画布完整专项或真实双机同步。既有偶发输入中断结论保持未解决。
- 平滑为保留原始点的邻点加权折线，不是压力模拟或曲线拟合；虚线按完整连续路径命中并整条擦除，空隙也可选中；四档粗细沿用旧约束。
- 新笔刷方案保存的是参数，不保存图形种类。工具默认只在会话内保留，自定义方案显式保存后可跨重启应用。旧版本服务端不了解新增字段，不应使用旧程序覆盖新数据。
