# 文件/设备入口与便签按钮去重

用户已明确“没有同步”指文件、局域网入口和重复按钮仍在。本次直接实施该范围；不是继续绘画工具批次，不更换存储或传输协议。

## 最终入口映射

| 原入口 | 现入口 | 保留能力 |
| --- | --- | --- |
| 侧栏共享 + 传送、页首共享、底部传送卡片 | 一个一级“设备互传” | 内部分别打开“设备连接与便签互传”和“白板实时共享” |
| 文件侧栏、底部投递槽卡片 | 一个一级“文件” | 复用FileStation，中转站/面板文件/回收站保留 |
| 便签顶部切换工作区 + 底部展开工作站 | 顶部“打开工作区” | 仍调用原expand/switchView，不复制草稿；底部保留保存、添加文件、加入关系画布 |
| 选中便签发送、待接收提醒、文件拖放、全局文件动作 | 原上下文入口 | 不作为重复常驻工作台导航删除 |

桌面命令面板同步采用“文件”“设备互传”。浏览器访客不显示桌面设备能力，保留白板共享入口。

## 兼容与视觉决策

比较“侧栏子菜单”“在同一个大弹层内重组所有业务”“轻量入口面板后进入原功能”三种方式，采用第三种：移动端可发现性更好，同时保留已有LAN状态、配对/确认/回执、白板共享互斥和文件状态。面板沿用主题token、细边框和现有弹层，不重新配色。

设备互传当前支持文字便签，页面明确说明；没有宣称新增文件发送。白板共享仍是原实时协议。文件仍复用现有弹层，未新增文件页或合并文件实体与引用。QuickPanel输入、保存、光标会话和窗口转换函数不改，仅删除重复按钮并统一名称。
