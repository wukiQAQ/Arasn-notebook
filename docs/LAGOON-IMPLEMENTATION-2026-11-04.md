# 轻泊正式实装 · 2026-11-04

交付：`release/ArasnNotebook-0.6.0-lagoon-win32-x64/ArasnNotebook.exe`。整个目录必须一起保留；从托盘退出旧版后再启动，避免单实例转发到旧程序。源码运行仍为 `npm start`。没有改存储协议或替换BoardClient，没有用浏览器会话模型替代正式业务。

## 已实装
- 完整页：轻量工具轨、单一新建入口、莓灰/暖深色主题、底部悬浮编辑工具、便笺纸面和适配内容。
- 文件：底部投递入口与模态抽屉接入真实FileStation，保留导入/多选/分类搜索/重命名/导出/引用/清空/回收站/备份恢复。
- 小窗：同一主题、品牌图标、圆润Tabs、文字/绘图/文件模式；原生展开/收回、隐藏和设置桥接保留。
- 命令：保留键盘搜索和真实动作，新增文件投递槽命令。
- 手机：正常字号的真实便笺编辑与画布总览切换；列表定位可滚动到便笺。暗色对文字做显示层提亮，原始颜色数据与PNG导出不变。

## 图标与动效
主操作使用原创24px符号，次级设置/共享等继续复用Lucide。`LagoonMotion.tsx`按语义控制原生Web Animations，不新增动画依赖：投递口轻开合、搜索微倾、画笔抬尖、新建抬升/按压回弹，其余图标小幅聚焦。180–230ms、无循环、可中断；不延迟命令执行，不给拖动指针加弹簧。鼠标hover只对鼠标触发，键盘click不触发按压动画；减少动态效果会取消在途图标动画。

| Before | After | Why |
| --- | --- | --- |
| 固定侧栏占较大宽度 | 76px工具轨与按需便笺列表 | 释放内容空间 |
| 顶部机械排布编辑控件 | 底部悬浮工具条，保留全部原工具 | 形成工具与内容的层级 |
| 图标统一悬停变色 | 按功能分别抬尖/开合/回弹 | 动效说明动作，不持续装饰 |
| 手机缩小画布阅读 | 16px文字阅读模式 | 避免缩放导致小字 |
| 原始深色文字直接落在暗面 | 仅显示层提亮颜色 | 改善阅读且不修改数据 |
