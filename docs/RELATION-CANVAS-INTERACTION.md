# 关系画布交互与动效 · 2026-11-12

## 审查与视觉决策

现有实现是 React 节点 + SVG 曲线，已有六类关系、引用数据、浮动属性面板、方向字段及节点视口裁切；无需引入图形库或更改存储。

用户是整理速记与内容关系的桌面使用者，首要任务是读内容、编辑节点、建立并理解关系。比较了内嵌操作栏（占正文高度）、独立浮动条（与节点分离）、顶部贴边操作栏，选择贴边操作栏；正文与已有主题保持优先。

设计 token 沿用 xigra 的 surface/text/muted/focus/border/success、现有字体与点阵。新增操作按钮高32px、最小宽38px、图标15–16px、字号13px、间距6px、圆角8px。锚点命中32px、可见圆点12px。控件反向缩放以保持屏幕尺寸。普通节点不常驻工具条；顶部不足60px时放到底部，左右夹取工具条位置。

## 第一阶段：节点操作

- 悬停预显编辑；单击/Enter选中后显示编辑、连接、更多。
- 编辑或双击打开原浮动面板；更多包含节点属性、打开原记录、移除节点。移除只隐藏画布引用。
- 连接按钮进入点选目标模式；点目标节点正文完成，Esc取消；原有右锚点拖到目标节点/左锚点继续有效。
- Esc优先关闭更多菜单或取消连接。按钮键盘焦点可见。
- 操作条在节点正文外；内容与布局尺寸不变。低缩放仅增大操作控件的相对显示，不强行放大所有节点内容。

## 第二阶段：关系语义

所有线默认静止；悬停、键盘聚焦、选线或选节点时增强。选节点时其关联线高亮，其余弱化；悬停弱化线可临时增强。自定义说明与关系类型共同显示，避免类型被说明覆盖。

| 类型 | 静态表达 | 活跃状态 |
| --- | --- | --- |
| 关联 | 实线 | 低透明流点，7秒一程 |
| 引用 | 圆点线 | 单向流点，5秒一程 |
| 依赖 | 稳定长虚线 | 流点3.6秒一程，1.2秒透明度脉冲 |
| 解决 | 略清晰实线 | 低饱和成功色流点，2.8秒一程 |
| 附件 | 更细、更轻的短虚线 | 小流点低透明，8秒一程 |
| 来源 | 圆点线 | 与引用一致 |

采用原生 SVG animateMotion，依赖脉冲使用 CSS opacity，无逐帧 React 更新。动画路径与连线共用同一贝塞尔路径。方向选择器支持起点到终点、双向、无方向；双向显示两端箭头及两个相向流点，无方向不显示箭头或流点。箭头通过 context-stroke 跟随线条颜色。

## 性能与兼容性

- 正常最多6条线运动（双向每线2个流点）；选中线和悬停线优先。
- 活节点>=100或边>=150：最多1条，周期放慢1.8倍。
- 活节点>=300或边>=500：全部静态。
- 缩放<45%、平移、拖节点或建立连接时暂停流点。
- prefers-reduced-motion 与 document.hidden 动态监听；禁用时卸载流点，静态类型标签、线型及高亮仍保留。
- 节点通过 Map 查找，避免每条边线性查找全部节点；沿用节点视口裁切。
- 实测 Windows Electron 45 / Chromium，1440、820、390px；没有新增依赖。未在独立 Firefox/Safari、低配机或原生触摸设备运行，不能把本机采样当作所有设备的帧率保证。SVG运动需目标浏览器支持SMIL，静态线型与文本是降级表达。
