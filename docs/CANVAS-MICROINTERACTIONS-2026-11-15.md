# 关系画布微交互与信息密度优化 · 2026-11-15

本轮直接按用户四项规范实施，沿用Graphite、现有记录/引用/关系/历史模型和API。用户提到的四张截图未出现在本轮附件中，以下定位和验收依据当前源码与实际Electron截图。此前“提示占文档流”的决策由本轮明确要求的浮动Toast覆盖。

## 定位与实现

| 问题与根因 | 修改后的行为 |
| --- | --- |
| main将短消息挂在页头下方，出现/消失改变可用高度；字符串状态无法刷新同文案计时，成功和失败共用短时生命周期 | 统一Notification组件和hook，body portal/fixed单条替换；用户设置成功约2秒后淡出，同文重计时；设置失败保留明确原因、重试及关闭按钮，重试仅写失败patch。画布选项的被动保存成功静默。160ms轻微淡入淡出/位移，减少动态时关闭动画。窄屏为缩放条、小地图和底栏预留空间 |
| SVG透明命中线已存在，但可视/命中描边在non-scaling-stroke基础上仍除以zoom；重叠由绘制顺序决定，同类型peer一起增强 | 18px透明命中与2px可视线独立，当前目标3.5px和沿曲线光晕；按曲线到指针的屏幕距离排序，距离差≤2px显示紧凑连接候选列表。悬停仅当前目标，点击选中、端点同步、无关线降权；线、标签、箭头保持同一语义色。键盘Enter/Space直接选中，避免SVG默认大矩形焦点框。候选出现时不重复显示tooltip，相机变化时关闭候选 |
| 历史按钮沿用轻微颜色差，快捷键信息在禁用时丢失 | 可执行按钮有选择底色/前景/边框，hover/pressed/focus-visible各有反馈，disabled透明底+明显弱化；保留native disabled与快捷键名称/aria-keyshortcuts，未改历史算法 |
| 每个节点固定显示“原记录摘要”、空摘要操作说明和已保存文字 | 标题优先；只显示真实摘要，通常最多两行，较短节点最多一行以免半行裁切；类型/必要任务状态移入底部。保存成功只用可访问的小图标，错误和待同步仍显示文字。低于60%时保留至少约11px屏幕字号的标题及异常标记，详细正文从原详情查看；原内容不重写 |

空白拖动画布、Shift+空白拖框选、Space/中键平移仍沿用既有约定。删除后撤销仍遵循原墓碑不复用ID的规则，恢复关系内容时创建新ID，本轮未改该机制。

## 修改文件清单

生产：

- `src/Notification.tsx`、`src/Notification.css`：统一通知状态、计时、动画、错误重试和渲染。
- `src/main.tsx`：通知接入、设置主动/静默反馈区分、旧占位提示移除。
- `src/relation-hit.ts`：无副作用的曲线距离排序与屏幕容差。
- `src/xigra/TopologyWorkspace.tsx`：候选选择、关系及端点状态、节点展示、历史按钮无障碍属性。
- `src/xigra/topology.css`：线条/节点/历史/候选列表局部样式。
- `src/FreeToolbar.tsx`：原撤销重做快捷键属性与禁用说明，复用相同状态规范。

测试：新增`tests/{relation-hit.test,canvas-micro-desktop,notification-desktop}.cjs`；`package.json`将命中单测接入默认测试；适配`tests/{status-notice-desktop,relation-motion-desktop,note-roles-checks,quick-recorder-desktop}.cjs`中被本轮新规范替代的断言/响应式探测方式。没有修改board或desktop存储代码。

文档：本文、`docs/superpowers/plans/2026-11-15-canvas-microinteractions.md`、`HANDOFF.md`。
