# XIGRA｜隙格 · 第 1 批实施验收

## 设计与范围

小窗用分格图标和双语字标建立识别度。冰白与深松绿区分窗口和编辑表面，薄荷色标出当前模式，保存反馈在底栏以圆点和文字并列。展开视图及现有窗口、数据和网络调用沿用原实现。

| 规范 | 定义 |
| --- | --- |
| 色彩 | 亮色窗口 `#F3F7F5`、品牌 `#184438`、选中底色 `#DBF2E8`。暗色窗口 `#11231D`、品牌 `#A6E1CB`、选中底色 `#28473A`。正文、次级文字、边界、焦点、成功、待处理及错误均有独立语义色 |
| 排版 | Segoe UI 与微软雅黑 UI。辅助 12/18、控件 14/20、正文 16/24、标题 18/26 px。字标采用 16 px 半粗字，中文辅助标注 12 px |
| 间距与形状 | 4/8/12/16/24/32 px 间距，6/8/10/14 px 圆角，1 px 描边。标题图标按钮的交互区域为 40×40 px |
| 层级 | 内容、浮层和对话框分别预留 0/20/30。浮层阴影采用 12 px 偏移与 32 px 模糊，按主题调整颜色 |
| 按钮状态 | 普通操作采用透明或描边底，主操作采用薄荷底。悬停和按下各有独立底色，禁用使用独立文字色，键盘焦点使用 2 px 描边。危险操作规范使用错误语义色及明确文案，现有危险操作的样式随对应模块单独接入 |
| 保存状态 | 已保存用绿底，排队或保存中用暖色底，有错误或冲突用红色底。状态文字从现有客户端读取，出错时优先提示待处理 |
| 动效 | 控件、模式、浮层时序为 100/120/150 ms。减少动态效果下时序为 0 ms，现有图标动画也尊重系统偏好 |

## 回归结果

| 检查 | 结果 |
| --- | --- |
| `npm run build` | TypeScript 与 Vite 构建通过 |
| `npm test` | 服务与存储测试 8/8 通过 |
| `npm run test:ui` | 双客户端共享文字、绘图、离线恢复与冲突保留 1/1 通过 |
| `node tests/xigra-batch1.cjs` | 四组尺寸与主题、保存、Tab、减少动态效果、隐藏、展开及收回通过 |
| `npm run test:desktop` | 默认全局快捷键注册、隐藏到托盘、局域网写入及停止共享、重启恢复通过 |
| `node tests/core-desktop.cjs` | 文件拖入、清空画板后保留文件、回收还原、剪贴板和重启恢复通过 |

本轮视觉证据来自一台 Windows 环境。物理全局热键、多屏缩放、Windows 系统高对比度以及中文输入法组合输入未做实机验收。
