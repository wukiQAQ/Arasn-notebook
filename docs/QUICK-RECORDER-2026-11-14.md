# 速记窗口布局与交互优化

## 设计与代码审查

面向随时记录想法的用户，首要任务是直接输入，其次切换最近记录，再添加文件或关联。原 QuickPanel 复用 RecordEditor 和 useRecordSession；正文单字段、名称取首行；Graphite 样式将新建按钮提升为主按钮，底栏的画布操作独占一行。

比较三种方向：胶囊切换（省空间）、横向预览卡片（预览多但占高度）、侧边列表（侵占正文且接近工作区）。选择胶囊切换。不要重新讨论这些：沿用现有石墨主题和语义色变量；新标题可选，不拆改旧正文；复用原自动保存、文件导入和关系引用业务，不自动启用画布。

设计 tokens：颜色继承 --desk / --surface / --ink / --muted / --line / --xigra-focus / --tint；字体继承项目字体，标题22px（短窗20px）、正文16px/1.85、操作12px、状态11px；窗口边距24px/窄窗16px，正文内边距24px，编辑区圆角12px、最近胶囊18px。重点通过标题字号和连续输入表面突出记录，不增加装饰模块或大按钮。

## 调整

- 两层轻头部：品牌/打开工作区/隐藏窗口；速记/搜索/新建。移除新建实底强调，保留键盘焦点边框。
- 中部独立标题和正文，标题可留空；启动、新建默认聚焦正文，标题 Enter 进入正文；标题200字符、正文10000字符。
- 底部第一层最多6条最近记录，可横向滚动和键盘访问，选中胶囊有边框与底色。
- 第二层统一保存状态、输入法状态/字数与文件/画布操作。460px以下折两行；短窗压缩头部和内边距。
- 标题为 text/node 的可选字段，服务器验证并保留，无数据库 schema 迁移；旧正文逐字保留。最近列表、便签搜索和关系画布显示标题，正文编辑保持独立。
- 切换恢复正文选区及标题选区；输入法合成期间禁用切换和辅助操作，保存复用原会话。

## 边界

- 源码/dist已更新，Portable/Setup EXE没有重打包。

- 添加文件继续按原业务存入文件区，不自动附着当前便签；独立标题不改变现有局域网正文互传协议。
