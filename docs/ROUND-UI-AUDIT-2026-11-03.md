# 三方案 UI 评审 · 2026-11-03

范围：实时访问 127.0.0.1:5178/round.html 的 afterglow / cove / mellow。仅评审，未改 UI 或正式业务代码。用户已认可 C 基础，本报告不重开 A/B/C 选型；下面的推荐尚非用户决策。

## 判断

- Cove：最适合作为继续打磨的产品结构，导航、画布、文件各有归属；缺点是容器嵌套多、右文件栏固定占地、工具与缩放分散。
- Afterglow：视觉辨识度最高，深咖和杏色、衬线标题有统一性；底部导航和左下新建分散，选中便签整面变浅会抢占视觉中心。适合作为同一产品的深色主题继续验证，不宜仅因截图漂亮就确定主布局。
- Mellow：最亲和，横向导航容易理解，下方文件条有临时收纳的语义；但背景、便签、文件条层级弱，顶部说明与底部文件条压缩画布，三个新建入口重复。

## 具体视觉方向

保留 C 的柔和纸面和圆润语气。以 Cove 的区域划分继续打磨，减少包裹层：外层24px、便签16px、控件10–12px可作为下一轮起点。右栏先试280–320px可调宽，默认按需打开；导航工具轨试64–72px；核心画布获得连续可用空间。只保留一个主要新建入口。

Afterglow 保留暖深底和杏色品牌强调；把选中态改为清晰描边/小标签，另保留用户选择的便签底色，避免选择动作突然把整张卡变成主视觉。工具、导航采用与浅色版相同的信息架构。

Mellow 保留莓灰强调色，正文便签以白色突出，底部文件条可折叠为约56px摘要条，展开再占空间；让文件条与画布有明确的边界。顶部抒情标题只在空白页/首次进入时突出，正常工作时换成可编辑工作区标题。

上述尺寸为设计建议，未经用户测试验证。颜色不凭肉眼宣称符合WCAG；本轮未做完整对比度、读屏或真实触屏审计。
