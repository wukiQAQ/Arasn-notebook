# Arasn · 轻泊：三方案融合与评审修复

依据 `ROUND-UI-AUDIT-2026-11-03.md`，本轮交付一个独立可运行 Web：`prototypes/studio.html`。正式 `src/` 与 `desktop/` 业务未改。旧 A/B/C 和 Mellow/Cove/Afterglow 比较页保留供追溯，融合版不再放方案切换栏。

## 主题与布局

**轻泊：让想法和临时文件有处停靠。** 面向在办公软件间快速切换、临时记录与收纳的人。主任务是记一句话，回找和文件暂存其次；界面不把产品说明当主视觉。

- Cove 提供区域关系：轻量工具轨、连续画布、独立文件区域。减少容器套容器，桌面工具轨76px（中屏68px），主画布只有一层边界。
- Mellow 提供纸面与语气：莓灰品牌色、白色正文便签、56px投递摘要条；正常工作时显示可编辑工作页名称，空白状态才出现引导。
- Afterglow 提供暖深色语言：深咖底、杏色品牌强调；同一结构切换主题，不因深浅变化搬动工具。选中态始终用轮廓与文字表达，不改变整张便签底色。

备选融合方式曾包括底部常开文件条、固定右栏；考虑评审的裁切/遮挡证据，选择默认收起的摘要条加模态抽屉。展开时明确进入文件模式，使用遮罩和焦点约束，避免工具与文件浮层混在一起。

## 图标、按钮和动效

`prototypes/src/studio/Icons.tsx` 原创19个24px网格glyph，1.65px圆头线条，折角纸张、投递口、开放式品牌符号保持同一家族。参考 [Iconoir官方](https://iconoir.com/docs/faq) 的轻量线条思路，未下载第三方图标资源或新增图标依赖。文件/命令次级图标复用现有Lucide。按钮按语义区分主动作的不对称小角、轨道的软选区、工具的紧凑方形和摘要条的投递口。

Motion仍为唯一动效库。便签进入160ms微缩放/淡入，拖动直接写MotionValue不加鼠标滞后；抽屉180ms微位移与透明度，命令面板使用连续高亮；没有持续循环装饰。支持prefers-reduced-motion，键盘焦点使用2px主题色轮廓。抽屉/说明/便签列表复用Base UI Dialog的焦点机制；未引入手势抽屉或重复组件库。
