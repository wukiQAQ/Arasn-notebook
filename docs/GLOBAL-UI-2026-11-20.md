# Arasn 全局 UI 专项 · 2026-11-20

## 审计清单

| 优先级 | 影响范围 | 发现与处理 |
|---|---|---|
| 1 | 图标按钮和普通关闭按钮 | 旧 `.icon-button`、共享按钮和浮窗标题分别绘制反馈。设置、设备入口及画布属性把 44 px 命中区整块填亮。普通关闭按钮接入 `IconButton`，热点和 28 px 视觉反馈独立。 |
| 2 | Button、Select、输入和键盘状态 | 旧按钮路径、共享按钮和 `AppSelect` 叠加样式。把下拉触发器交给 `AppSelect`，让悬停、选中、按下和焦点各有明确样式。复用原生单选、复选和滑块交互。 |
| 3 | Dialog、Popover、菜单和工具栏 | 浮层混用输入边框和不同的阴影。弹窗、浮层、工具栏分别用对应阴影。关系菜单将键盘焦点从指针悬停中独立出来。 |
| 4 | 设置与设备互传 | 设置正文的分组卡片、布局分隔和预览边框重复。去掉装饰性外壳，保留必要分隔和主题预览。设备入口改用柔和的填充，选择、监听和风险信息仍保留各自层级。 |
| 5 | 工具属性、便签和文件 | 画笔与橡皮擦的参数对齐不同。便签列表的常驻描边、文件行悬停和操作反馈过重。统一参数行、精简列表描边，并保留选中、复选、文件导入和拖拽所需的边界。 |

## 视觉和主题

比较了用连续分隔线布局与用表面明度和留白区分层级两种方向。采用后者，便签纸面和画布保持现有结构，设置用左侧导航和直接排列的设置行。沿用 Segoe UI、微软雅黑及用户选定的界面字体。界面强调色继续由外观设置生成，深色主题会为可读性调整实际渲染色值。

| 令牌 | 使用方式 |
|---|---|
| `--ui-surface-field`、`--ui-border-field` | 浅色 `#f5f6f8`、`#d1d5de`，深色 `#252932`、`#4a515e`。用于需要可见边界的字段。控件的悬停通过已有控件边界令牌提高对比度。 |
| `--ui-surface-floating`、`--ui-shadow-floating`、`--ui-shadow-modal` | 下拉、工具属性、附件面板采用对应浮层表面和阴影。模态弹窗有更深阴影。工具栏采用较浅的卡片阴影。 |
| `--ui-radius-control`、`--ui-icon-hit*`、`--ui-icon-face` | 常规圆角 8 px。普通和紧凑图标命中区域为 36 px 和 32 px。原有 44 px 关闭热区继续采用 44 px。视觉反馈为居中的 28 px。 |
| `--ui-motion-*`、`--control-motion` | 悬停 140 ms、按下 100 ms、浮层 160 ms、弹窗 190 ms。新增过渡遵循系统减少动态效果。 |
| `--ui-nav-active`、`--ui-nav-on-active`、`--ui-focus` | 延续现有主题的强调色派生值。选中显示软底色，键盘焦点使用单个焦点指示。 |

## 共享组件与页面适配

| 页面或组件 | 适配 |
|---|---|
| `Button` / `IconButton` | 通用按钮共享圆角、禁用和交互时间。图标关闭覆盖设置、设备、实时共享、局域网便签、工具属性、画布关系详情和连线选择、便签详情与查找、附件选择和预览、导出及通知。 |
| 字段 / `AppSelect` | 共享下拉样式覆盖外观、网卡、工具属性和关系详情。颜色、文本和数字字段通过 `.ui-field` 接入。滑块保留原生键盘和指针操作，统一轨道区域尺寸与强调色。 |
| 顶部和导航 | 普通和紧凑导航的选中操作复用弱底色。窗口与页面工具栏复用浮层圆角和阴影令牌。 |
| 便签库、编辑器、全局搜索 | 列表去掉常驻装饰描边，当前便签继续可辨。编辑器间接采用共享动作状态。搜索保留现有玻璃表面和匹配状态。 |
| 自由工作页 | 画笔、橡皮擦、图形、文字和对象属性共用同一浮层。参数值和下拉靠右，范围控件独占下一行。保留实时笔刷预览、HSL、预设、擦除模式和碰撞定位。 |
| 关系画布 | 工具栏、节点详情的关闭和固定、连线选择及上下文菜单对齐公共反馈。节点、拖拽、连线语义仍使用各自状态。 |
| 文件与附件 | 选择弹窗、预览和附件面板接入关闭组件。列表选中保留边界，悬停边框降低对比度。文件选择和拖放仍有可辨的反馈。 |
| 设置全部分类 | 外观、快捷键与触发、窗口与启动、数据备份共用原有导航和内容滚动策略。外观分组改用设置行，主题预览保留选中勾。窄窗继续采用分类和详情两步进入。 |
| 设备互传、局域网、白板共享 | 入口卡片按图标、标题、状态、箭头对齐。网卡下拉采用公共状态，配对、共享和风险告知沿用原来内容。当前文件页的传送入口仍通往设备互传。 |
| Toast、确认、Tooltip、空状态 | 通知关闭接入同一组件，确认取消动作接入共享按钮。工具提示沿用已有触发和延时。空状态、等待和错误文案通过既有主题与状态组件呈现。 |

网络协议、数据结构、落盘格式、画布对象格式和 Windows 窗口按钮的实现均未改动。

## 验证与范围限制

| 验证项 | 结果 |
|---|---|
| 构建与单元测试 | `npm run build` 通过，`npm test` 92/92 通过。 |
| 真实 Electron 视觉及交互 | `node tests/global-ui-desktop.cjs` 覆盖 100% 浅色、125% 深色、150% 浅色，每档切换两种主题，校验自定义强调色落盘和实际按钮色变化。检查普通窗、约 520 × 420 DIP 窄窗及最大化，测量关闭热区与反馈，验证按下、键盘、禁用、复选框选中后悬停、减弱动效、全部设置分类、工具属性、绘图、局部擦除与撤销、关系节点、文件和搜索。 |
| 便签、文件与附件 | `node tests/unified-notes-desktop.cjs` 通过，覆盖文件导入、预览、附件管理、工作页及关系画布联动和 Windows 热键。 |
| 设备与共享 | `node tests/lan-notes-desktop.cjs` 通过，两个隔离 Electron 进程走完整的回环配对、发起、接收和保存确认。`npm run test:desktop` 通过，覆盖 LAN 白板写入、停止共享和重启持久性。 |

DPI 使用 Windows Electron 启动参数并读取实际 `devicePixelRatio`，本轮使用单显示器上的独立测试实例。实体触控、跨显示器 DPI 切换、实体设备之间的配对及每一组自定义前景与背景组合未实测。文件页的设备入口沿用已有能力，目前可互传便签。

旧版专项 `relation-canvas-desktop.cjs` 完成连线、关系类型修改和说明保存后，在旧版「添加到关系画布」入口超时。`drawing-tools-desktop.cjs` 完成笔画创建、整条擦除和撤销后，在旧版「工具属性」按钮超时。当前入口由上表的专项覆盖，关系连线后续旧脚本步骤未完成。
