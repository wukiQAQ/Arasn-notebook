# 关系连接线视觉结构统一

## 审查与实现

原组件已共用relationGeometry贝塞尔路径和开放式marker，但每个关系类型仍附带dash、width、seconds、radius、opacity、pulse配置；选中后渲染移动箭头。旧宽度配置还被CSS末尾固定2px规则覆盖，形成重复来源。CSS外层世界缩放会把描边一起缩放，原vector-effect并没有抵消这层HTML变换。

本轮将外观配置收敛到亮/暗语义颜色，保留所有关系枚举和数据：关联蓝、引用紫、依赖橙、解决绿、附件青；既有“来源”仍保留，继续用紫色。未合并或重写保存的类型。

- 全部使用同一种平滑三次贝塞尔实线，默认屏幕2px；hover、选中、键盘聚焦为2.5px并调整语义色亮度。
- 有向关系采用统一开放式细箭头：同一M 2 2 L 8 5 L 2 8形状、1.25px细描边、约10px屏幕尺寸，orient=auto-start-reverse沿端点切线；none不画箭头，forward保留末端，both保留两端。不因类型强制改变已有方向。
- 删除移动箭头、SMIL animateMotion、类型脉冲以及对应媒体监听和动态边集。默认、悬停和选中均不再出现独立循环动画。
- 线、箭头、标签继续共用relationTokens颜色映射；移除非焦点关系的整体半透明，避免文字标签随选择变得难辨。
- 标签统一24px高、5px圆角、1px 8px内边距、12px/20px字体；保留标题提示和长文本省略。
- 在SVG中传入当前缩放，仅补偿视觉描边：默认2px、焦点2.5px、透明命中区18px保持屏幕尺寸。箭头和标签沿用原逆缩放方法。
- 连线创建预览也改为实线，仅用轻微透明度表明未提交状态。

## 短连接与交叉

复用原端点、曲率和标签碰撞计算，仅对短且分离的卡片间距收敛控制柄与端点留白，保证控制点单调，不在短间距回折。长线及水平重叠卡片维持原计算方式。

首轮发现原标签候选偏移不足以绕开短线两端卡片，放大后尤其明显。最终增加按卡片高度与缩放计算的候选位置；标签占位仍沿用原28px空间，不改变节点或关系数据。

测试场景包含多条交叉、双向短线、反向/纵向、无向关联和不同缩放。未增加全图自动路由、跨线跳桥或节点重排；极小屏幕间距仍可能让双向箭头接近，应放大或拉开节点查看。

## 验证

- npm run build通过，含TypeScript和LAN bundle。
- npm test：71/71通过。新增短线在25/50/100/200%及左右方向不回折，短标签不覆盖端点卡片。
- relation-structure-desktop通过：六个既有类型、五种语义色、同形箭头、统一标签、无SMIL/移动箭头、无向/双向/方向编辑、键盘、亮暗、交叉、短连接、51/100/200%及390px；所有默认描边为屏幕2px，焦点2.5px，命中区18px、箭头约10px。
- topology-desktop通过：原便签、类型/状态、拖动历史、相机、小地图、重启、恢复、窄屏、创建与减少动效。
- relation-motion-desktop通过：同色线/箭头/标签、端点切线、关系类型、双向/无向、菜单/Escape、100/300节点与500条关系静态渲染。只保留短时帧采样，不作长稳结论。
- workspace-interactions-desktop通过：文件引用保护、重启、连接复制粘贴、方向/端点编辑、连接删除后的撤销恢复与撤销重做；最终状态重启后相同。首次失败是旧测试入口“关闭文件”已不存在，适配正式文件页返回名称后通过。

标签与自身背景的实际最低对比度5.1077:1（覆盖两主题/焦点），不把此结果扩大为完整WCAG审计。

短标签测试首次在200%失败，原因是固定偏移未覆盖放大的卡片高度；改为高度相关候选后通过。没有降低测试断言。
