# Arasn 智能触发器实施方案

保留 SQLite 版本化配置、现有 Windows 键盘注册和单个 Raw Input 接收窗口。所有识别器交回同一动作派发入口，沿用窗口位置、焦点、草稿和输入法保护。

1. 注册表增加持久化暂停和临时测试模式。暂停释放已注册资源，测试只反馈命中。先复跑旧键鼠和窗口回归。
2. 在鼠标入口识别按住后移动的路径，录制与原生识别共用方向算法。无修饰键的全局右键或中键拖动须明确确认。全局手势避开 Arasn 正在编辑的窗口。非全局手势限定在窗口标题工具区。
3. 在同一鼠标入口接入屏幕热区。以工作区内侧作停留范围，排除相邻显示器占据的边界和任何按键拖动。停留到点再检查光标、修饰键和前台范围。
4. 复用一扇小尺寸、不可聚焦、鼠标穿透的透明提示窗口。仅在候选热区出现，停留进度在渲染层变化。主窗口入场方向使用短幅内容过渡，保留窗口外框位置。减少动态效果时使用静态提示。

设置沿用现有弹窗和 Tokens。考虑过为手势和热区分别创建弹窗，以及把所有编辑控件一直展开。采用类别切换和就地编辑，保留一条清楚的动作、状态与冲突路径。

## 实现约定

- 保留配置版本 1 和现有键鼠绑定。每条绑定可指定名称与动作。新增 `gesture` 保存鼠标按钮、修饰键、1–4 段方向、最短距离、容差、超时及作用范围。路径只在本次录制或识别期间短暂存在，配置仅保存方向序列。设置页「测试触发器」把命中回传给界面，期间跳过业务动作。
- `edge` 保存八个区域之一、热区宽度、停留、冷却、所需修饰键、桌面条件和全屏条件。同一区域只有一条启用的绑定。参考值为 8 DIP、450 ms 和 1,000 ms。显示器边界和工作区读取 Windows 原生物理矩形，宽度按各显示器缩放换算。接缝排除和任务栏避让先于命中。冷却期间仍需重新进入，持续停留只触发一次。
- 原生鼠标输入复用一份 Raw Input 注册。移动只在启用热区或按住匹配的按钮时合并取样。没有定时轮询，只有候选停留、手势超时和短过渡的单次定时器。点击仍由 Windows 送往原应用。
- 反馈采用 64 × 4 DIP 的可见条。Windows 可能为它保留较大的透明外框，外框同样设置鼠标穿透和不可聚焦。进入候选区域时逐步增强，退出淡出。全局关闭反馈后，边缘仍可执行动作。

参考 [Windows Raw Input](https://learn.microsoft.com/en-us/windows/win32/inputdev/about-raw-input) · [Electron BrowserWindow](https://www.electronjs.org/docs/latest/api/browser-window)

## 验收

Windows 隔离验收入口为 `node tests/trigger-desktop.cjs --mouse --smart --edge --feedback`。已有测试覆盖键鼠回归、L 形录制与原生识别、右键按下及松开透传、测试模式、热区配置与独立禁用、桌面限定、全屏覆盖检测、候选停留与锁存、提示层原生焦点和穿透标记、减少动态效果、20 次监听启停及重启恢复。混合缩放、负坐标、接缝、任务栏和热角优先级另有纯几何测试。

**待人工验收**

1. 在不同 DPI 的物理双屏试八区，覆盖横向／纵向错位、共享边界、任务栏换边、自动隐藏、主副屏切换和拔插。
2. 在浏览器与文件管理器用物理鼠标复测右键菜单、中键滚动、侧键导航、文件拖放和文字选择。启用手势后复核 Arasn 画笔和便笺编辑。
3. 在全屏浏览器、播放器及独占全屏游戏验证自动暂停。远程桌面和厂商侧键驱动需分别试用。
4. 以高回报率鼠标运行数小时，比较启用与暂停时的 CPU、内存、后台窗口数，观察屏幕重连后的监听与提示释放。
