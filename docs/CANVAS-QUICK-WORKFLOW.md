# 关系画布与速记整合：第一批

## 审查与兼容方案

当前 TopologyWorkspace 的详情 aside 作为 topology-frame 的 flex 子项占据 245–300px；current 来自 selected，导致单击直接打开详情。速记 onCanvas 调用 switchView(true)，随后由画布 effect 创建引用，缺少成功前的可靠保存确认。

本批增量替换：分离 selection/inspectorOpen；通过 portal 把属性面板放入 topology-surface 的绝对定位层；坐标取现有 camera/size/layout 转换结果，仅写浮窗会话状态。320px 浮窗按空间翻转/夹取位置，可拖动及固定，关闭不取消节点选择。复杂编辑仍打开原记录。

加入画布复用 BoardClient：先 flush 正文，验证当前 room 和原 ID，检查已启用的默认画布，去重并创建/恢复引用，再 flush 引用；失败不显示成功。正文与引用仍独立版本，失败操作保留在原恢复队列。只有一个默认画布时不强迫选择；多画布创建和选择不在本批引入。没有数据库迁移或共享协议修改。

依赖顺序：共享空位放置/可靠加入 API → 速记底部原地加入与查看节点 → 浮动属性面板与独立打开状态 → 故障/交互/截图回归。

## 修改文件

- src/topology.ts、src/board.ts：共享放置与可靠引用加入。
- src/QuickPanel.tsx、src/main.tsx：底部保存/加入/展开入口，加入后停留原界面、显式查看节点。
- src/xigra/TopologyWorkspace.tsx、topology.css；新增 FloatingInspector.tsx：选中/编辑分离、绝对浮层、位置约束、拖动与固定、焦点恢复及减少动效。
- tests/board-client.test.cjs、topology-desktop.cjs、relation-canvas-desktop.cjs：扩展保存故障和工作流 Electron 验收。

视觉沿用浅灰画布、白色内容节点、灰阶工具栏与克制蓝色焦点。浮窗用主题玻璃底、细边框与轻阴影，出现150ms，仅 opacity/translate，不触发布局动画；减少动效关闭动画。

## 验收标准

进入画布无详情；单击仅选择；双击/编辑才开浮窗；开关/拖动/固定不改变 viewport 尺寸、相机、节点或边坐标；四边及390px不溢出；输入焦点稳定，关闭保留正文且返回选中节点。速记加入不自动展开，等待正文及引用落盘后才成功，重复加入不复制正文或节点；失败提示且保留草稿/待提交操作；删除引用保留原文，原记录墓碑显示失效提示；重启恢复。

## 后续批次审查

统一唤出继续复用 trigger-registry、main 动作分发、window-manager 和 records/session，不重写持久化。当前已有多绑定、暂停、测试、鼠标/手势/边缘触发和失败保留配置机制；新增默认目标、重复触发策略与last界面配置留在第二批。

键盘扩展先检查现有 Windows RegisterHotKey 适配与录制校验：操作系统注册成功才允许全局功能键；字母/数字单键仅在本应用非文本输入、非输入法组合时生效。全局字母单键仅做可行性评估，不宣称能识别第三方输入框；本批不添加 Hook 或修改触发器行为。

实际代码已接受 F1–F24 的无修饰功能键格式，Windows 适配显式拒绝保留的 F12；第三批重点是作用域、录制与失败提示，不重复实现已有功能键解析。

## 第一批实现结果

- 新增 FloatingInspector，320px，按节点世界坐标经当前相机转换到屏幕坐标，自动左右避让、限制四边；拖动或方向键移动后固定在当前浮窗会话位置，可解除固定。窗口改变时继续夹取到可见区域。未创建操作系统窗口。
- 单击/回车仅选择；双击或“编辑”打开；新建节点属于显式编辑动作。关闭只隐藏浮窗并返回节点焦点；离开画布关闭编辑浮窗。关系编辑和恢复列表也使用同一浮层，均不参与 flex 分配。
- 正文自动保存仍使用原 BoardClient；组合输入期间阻止关闭或打开原记录，异步加入完成后若已离开页面，不再后台定位相机。
- 连接设置默认折叠，正文提供打开原记录入口。浮窗出现150ms，减少动态效果时关闭动画。最小窗口不再继承旧侧栏55%高度限制。
- 速记底部包含保存状态、加入、展开；加入保持速记界面，可靠保存后出现成功/已存在与“查看节点”。矮窗口将操作压到紧凑行，保留原有至少250px输入区的回归标准。
- 加入 API 对同一 room/record 合并并发请求；先保存正文、核对原 ID/默认画布，再创建或恢复引用并确认落盘。失败保留原队列；重试不复制正文或引用。结束时再次校验原记录和引用目标，避免把失效引用报作成功。

## 本批边界

仍只有一个默认画布，不新增多画布选择/创建或迁移；未实现可选固定侧边模式。浮窗手动位置仅在当前打开会话内保持。统一默认唤出目标、重复触发策略、局部单键和实验性全局单键均未改动。

输入法验证包含现有转换/焦点回归与组合事件保护；本轮未重新进行物理微软拼音、混合 DPI 多屏、原生鼠标手势和两台物理设备局域网专项。相关注册表/手势/网络单测仍通过，业务实现未重写。第二批应先复用现有动作分发与 WindowManager 增加默认目标设置，再专门跑原生触发/草稿/输入法回归。
