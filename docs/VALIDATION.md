## 两机试用步骤

1. A 启动 exe、写字和画图、开启共享，复制实际局域网网卡的链接。
2. B 在同网络用浏览器打开，确认内容可见；B 输入和绘图后确认 A 更新。
3. 同时修改不同便笺，再同时修改同一便笺；后者应保留冲突副本。
4. B 断网继续输入，再恢复网络，验证补发；本步骤不要让主机重新生成链接。
5. A 停止共享，B 应无法继续提交；A 重启后本机内容仍在，共享默认关闭。
6. 记录系统、网卡、网络限制、错误信息和延迟，再解决现场问题。
