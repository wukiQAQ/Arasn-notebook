# 工作区配色第三批 · 2026-11-15

接续主题第二批，统一现有Graphite界面的颜色角色。选择中性表面＋靛色操作/选择＋绿色成功/琥珀警告/红色错误；高饱和导航和暖色纸面会改变既定方向，未采用。字体、间距、布局、模型/API与关系类型色保持原约定。

## 实现

- `src/xigra/tokens.css`：graphite层级及xigra正文、次要文字、操作/操作文字、选择/选择文字、边框、焦点、hover/pressed、禁用与阴影别名接入同一套ui角色。新增subtle/pressed角色，亮暗控件边框分别为#7d879a/#77859d。成功/警告/错误沿用既有成对语义色和文字标签。
- `src/xigra/graphite.css`：主按钮使用操作背景与成对前景色，修正旧规则用纸面色充当深色按钮文字的问题；文件搜索、分类、文件选择器搜索与关系搜索使用控件边框角色。
- `src/free-canvas.css`：自由画布底色使用统一canvas角色；不改用户内容的color字段、点列、正文、对象坐标、历史或关系色。
- `tests/color-batch3-desktop.cjs`：真实Electron配色、对比度、导航hover/键盘焦点/禁用分页、四页/速记/弹窗、整份board保护专项。

浅色背景#f3f4f6/纸面#fff/正文#262932/操作#5d4bd2；深色背景#1b1e24/纸面#282c34/正文#eef0f4/操作#6954d8。焦点在深色使用较亮的#b6a7ff，选择使用低饱和底色与边线，不把悬停当选中。用户自选色与关系类型色保持独立语义。
