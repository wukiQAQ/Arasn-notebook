# 导航与自由画布响应式自适应 · 第一批 · 2026-11-16

## 审查与方案
已读AGENTS.md/HANDOFF.md及FreeToolbar、NavItem、free-canvas/sidebar样式、useFreeViewport和原生窗口限制。根因是导航208/184/68等旧媒体查询覆盖、工具栏104px固定宽度与基于100dvh估算高度，未根据真正的画布空间分级；标签/分组累积纵向高度，缩放整个界面不能解决。
比较过纯窗口媒体查询（不能覆盖面板与实际画布尺寸）、容器实测并分级（采用）、改变画布布局/等比缩放（会牵动画布，不采用）。本批不改数据兼容性、路由、持久化格式或原生窗口策略。

## 已实施
- 导航：完整208px、紧凑168px、折叠64px；文字字号与图标尺寸保持可读，保留主导航分组、唯一选中及图标专属圆底/阴影。
- 折叠时可通过按钮覆盖展开208px导航，不改变画布几何；Esc关闭并恢复按钮焦点。各导航、设置与展开按钮保留可访问名称，图标模式支持Hover/Tab Tooltip。
- FreeToolbar：完整104px图标+文字，紧凑52px图标，极简52px只显示选择/画笔/橡皮擦/文字与更多；图形、附件、历史、属性、删除移入基础更多浮层。所有操作沿用原回调；图形在更多内选中时，更多按钮显示图形图标与选中反馈。撤销/重做/删除保留disabled语义与状态。
- `useAdaptiveLayout`使用外壳ResizeObserver及现有paper-scroll实际尺寸，读取打开的属性面板实宽扣除可用区域。按CSS像素计算，Electron缩放与DPI已体现在布局空间中，不重复乘DPR。
- 默认导航阈值1200/960及高度640/560，工具栏按可用画布宽度880/440及高度590/490分级；退出阈值有24px迟滞，100ms合并测量。它们是实现起点，不是固定窗口等比缩放。
- 正在绘制/平移等真实画布指针手势期间冻结模式；pointerup/cancel/blur后重新评估。工具栏以实际可用高度限制并保留独立滚动作为瞬时变化兜底。
- 不重新挂载画布、编辑器或属性面板，不写内容坐标、不调用系统窗口尺寸API。继续使用既有亮暗tokens与减少动态策略，无新装饰动画。
