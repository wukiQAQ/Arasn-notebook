# 便签与文件页精修

用户：在普通桌面窗口中浏览、编辑便签并管理附件。优先保证正文可读、选择稳定和操作可达；不改保存、文件 API 或画布坐标。

方向比较：连续双栏编辑器（选用，适合持续浏览编辑）；独立卡片库（削弱编辑主次）；上下堆叠（短窗口正文高度不足）。

设计：沿用石墨深浅主题及 visual-order 语义色，导航用 nav/card 两层表面，正文使用 card。标题 16px/600、列表标题 14px/500、正文 16px/1.9、辅助信息 12px。间距 4/8/12/16/24/32，圆角 7/10px。所有选择控件保持固定字重；背景、文字、边框、阴影 180ms ease-out，尊重减少动态效果。

步骤：审查现有结构与窗口规则；实现摘要和编辑器层级；统一选择状态；实现分级窗口与更多菜单；真实 Electron 截图、几何/交互/保存回归；交接。

断点：>1200 双栏（左栏 260–320）；901–1200 左栏 240、简化正文操作；<=900 列表/正文单栏切换（主导航 <=1000 缩为图标轨道，<=639 保留底部导航）。桌面原生最小窗口继续 720×520，390 仅为附加抗压测试，不改原生窗口策略。文件操作使用容器断点，避免仅依赖整个窗口宽度。

## 修改文件
- `src/note-file-polish.css`：统一状态过渡、导航轨道、便签层次及窗口适配，文件 880/540px 容器断点。
- `src/xigra/records/RecordWorkspace.tsx`：列表/正文切换、窄窗操作菜单、新建自动转正文。
- `src/xigra/records/RecordList.tsx`：独立标题便签显示完整正文摘要，单行便签提供辅助提示。
- `src/xigra/records/RecordEditor.tsx`：隐藏时不抢焦点，重新显示时恢复原选择位置。
- `src/FileStation.tsx`：顶部更多菜单与行菜单补齐收纳操作，沿用原处理函数。
- `src/main.tsx`：引入精修样式。
- `src/sidebar.css`、`src/xigra/graphite.css`、`src/xigra/primitives.css`：删除选中态加粗规则。
- `tests/note-file-polish-desktop.cjs`：独立临时数据的真实 Electron 截图、字重/过渡/焦点/保存与窗口回归。
- 本文及 `HANDOFF.md`：设计、验证与交接。
