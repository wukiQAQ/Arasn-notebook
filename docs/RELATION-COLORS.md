# 关系语义色系统 · 2026-11-12

## 最终视觉决策

用户首先要求固定关系语义色，随后明确要求加粗和提高饱和度。选择线、字、细边框着色；不使用整块彩色标签或发光。既有节点正文、点阵与亮暗主题保持。候选的整块标签、纯单色线加彩色标签均未采用，前者更抢眼，后者不利于直接沿线辨认关系。

所有色值、线宽、虚线、流点大小/透明度、运动周期与脉冲开关集中在src/relation-appearance.ts。satisfies Record约束要求现有每个关系类型都有配置。新增已被业务模型接受的关系类型时补充配置即可；新增业务关系类型本身仍需同步存储校验，不应只加颜色。

## 行为

- 默认按类型着色，保持静止；线、标签、箭头、流点读取同一配置。
- 悬停或键盘聚焦只提亮同色相、加粗0.5px；实际两端节点细边框和锚点联动。焦点提示放在标签外圈，不将18px命中区绘制成粗色带。
- 选线时，同类型线保留同色强调，其他类型透明度52%；选节点时其关联线强调，其余弱化。当前线/节点关联线比同类线略粗。不会让所有同类关系一起运动。
- 箭头按类型共享普通/强调两个SVG marker定义，总计12个，避免逐边复制和context-stroke兼容差异；仍支持单向、双向与无向。
- 详情类型标识、折叠颜色图例使用同一配置；图例默认关闭。
- 现有动效预算不变：常规最多6线，>=100节点或150边最多1线并减速，>=300节点或500边静态；减少动态效果、后台、低缩放、平移/拖节点/连接时停动。无新依赖、无逐帧React状态更新。

## 沿线流动箭头

用户确认希望箭头沿连线流动，而不是仅在端点跟随节点。现使用同色开放箭翼替代原流点，端点静态箭头保留。移动箭头的SVG路径与连线相同；auto/auto-reverse使正反向箭头沿切线朝实际移动方向，测试通过局部+X轴与真实位移方向点积>0.9验证两方向。箭翼加大以避免被4px线条淹没，描边保持屏幕2px。

仍仅选中/悬停时按原预算运动，双向相向移动，无向没有箭头；减少动态、后台及高负载继续静态降级。没有新增逐帧React更新或依赖。

构建与完整关系专项通过（含颜色、位移、双向朝向、无向、390px及压力降级）。一次静态采样出现约1秒间隔，复核时在每组前恢复窗口焦点并记录可见性；最终四组均visible/focused，静态P95约6.1ms，300节点500边平移P95约12.1ms，无>32ms。仍是本机短时采样，不能代表其他硬件。

实际运行帧合成动图：docs/screenshots/relation-flow-arrows/arrows-moving.gif；截图及performance.json在同目录。用户可通过ARASN_FLOW_PREVIEW=1运行专项生成临时截图帧后合成；本轮帧目录已清理。源码与dist更新，EXE未重新打包。
