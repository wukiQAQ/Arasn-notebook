# 便签系统第二批：工具栏与操作边界

第二批完成，停在第三批之前。沿用第一批数据模型、Graphite深色主题和现有SVG笔迹，不迁移数据、不新增依赖、不打包EXE。

## 审查与改动

审查确认：原选择工具在空白处也会启动平移；工具栏没有分类和文字；图形与画笔可能同时激活；对象事件可能截走画笔/擦除操作。现有笔迹级橡皮擦已支持命中范围、光标、撤销，继续复用，未重复实现。

| 分类 | 工具与最终行为 |
|---|---|
| 导航 | 选择：选中对象、拖动便签/附件抓手或笔迹、调整对象；空白只取消选择。平移：移动整个视口，跨便签/附件也不会移动对象；原中键互斥保留 |
| 创作 | 画笔、橡皮擦、文字、图形、附件；图形与自由画笔只激活一个；按钮有文字、图标和详细title |
| 历史 | 独立撤销/重做组，保留原100组会话历史、ID重映射和冲突保护 |
| 对象操作 | 工具属性；删除仅在选择工具且有选中的text/stroke/free-file时启用。Delete键同样受限；便签/附件自身移除按钮也要求选中 |

画笔/擦除时便签与附件通过inert隔离，不能误编辑、拖动或触发删除；手掌可直接跨过它们平移。文字工具保留编辑已有便签的能力。自由画布增加可聚焦区域，状态提示区分选择与平移，清理旧“选择空白也平移”的提示。

橡皮擦明确标记为**整条笔迹**：命中即删除整条stroke（包括既有形状stroke），一次拖动为一组，可撤销/重做；不是像素或局部擦除。原12–96px屏幕范围、可视化圆环和取消回滚保留；范围入口与属性合并，避免两个重复入口。擦除时不显示无关对象坐标属性。第三批才完整拆分其余工具属性。

## 修改文件清单

- 新增`src/FreeToolbar.tsx`：导航/创作/历史/对象分组、文字与图标、唯一激活态、提示、删除使能。
- `src/main.tsx`：工具栏接入；选择空白不平移；删除工具条件；笔迹操作时便签inert；画布键盘焦点/说明；擦除范围标识与相关属性过滤；移动端阅读视图的选中删除约束。
- `src/FreeFileCard.tsx`：按工具启用交互；移除按钮要求当前选中，保护导出与托管副本逻辑。
- `src/free-canvas.css`：竖向文字栏、短窗口栏内滚动、独立属性弹层、各工具光标、对象保护和移动端布局。
- 新增`tests/tool-logic-desktop.cjs`：隔离真实Electron工具行为/数据保护/响应式回归。
- `tests/free-canvas-desktop.cjs`：按新产品约定用手掌执行平移；仍严格验证取消、坐标、旧数据、导出等。
- `tests/free-content-desktop.cjs`：显式先选择目标附件再移除；保持原件/托管文件保护与Undo断言。
- `tests/{drawing-tools-desktop,free-canvas-desktop,free-content-desktop}.cjs`：支持`ARASN_VISUAL_SHOTS`，本轮证据另存，保留原截图。
- 本报告、`docs/superpowers/plans/2026-11-14-tool-logic-batch2.md`、`HANDOFF.md`；构建更新`dist/`。

## 尚未解决的问题

- 最初一次新增专项的擦除数量断言失败，诊断重跑及最终完整回归通过；该首次失败没有充分事件证据定位根因，不能认定旧偶发输入中断已解决。后续失败脚本保存pointer事件，但不能用后续通过反推首次根因。
- 未进行真实物理键鼠、触控/触控板、混合DPI、Win32前台/置顶或长稳验收。CDP输入及本机回归不替代这些项目。
- 短窗口低频操作需要滚动工具栏；本批未增加图层/对齐/框选，也未新增像素擦除、橡皮软硬度或画笔高级参数。
- 本次未重跑局域网双机/关系画布完整专项；未改存储、共享协议或关系模型。前批的单条便签附件绑定缺口仍保留。

## 第三批建议

先按当前工具拆分属性面板（选择/画笔/擦除/文字），高频颜色与粗细常显，低频颜色和笔刷参数折叠。沿现有StrokeValue增加可选且有旧数据默认值的参数；实现快速色板、整套预设、HSL/透明度、平滑与端点/笔刷真实渲染，再考虑自定义方案持久化。未有实际实现和验证的压力/软边能力不能只画一个开关冒充支持。
