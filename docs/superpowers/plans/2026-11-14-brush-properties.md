# 第三批属性与画笔预设

目标：按工具拆分属性，提供真实笔刷渲染与安全保存的自定义方案。接续 HANDOFF 的第三批授权，保留 Graphite、旧记录和历史模型，无新依赖。

设计：比较固定右栏、独立设置窗、现有浮层，选择浮层以保留画布面积。Segoe UI/微软雅黑，12px标签、13px正文、8/12px间距，沿用 surface/line/ink/brand 语义色。高频色板/粗细常显，HSL/笔刷细节折叠；选择仅显示对象相关属性，手掌说明平移，橡皮仅范围，文字仅文字属性。

- [x] 新增笔刷参数/颜色转换/路径与预设校验测试；默认旧笔迹保持不变。
- [x] StrokeValue 与服务端可选字段；SVG和PNG共用路径/端点/虚线。
- [x] 独立属性组件、内置预设、桌面设置保存/删除自定义方案，失败可见。
- [x] 构建、单测、隔离Electron专项，桌面/820/390截图两轮检查。
- [x] 更新报告和交接，不打包EXE。

重点边界：损坏预设、非法数值、保存失败、选中对象与工具默认隔离、旧笔迹/撤销/重启、窄屏滚动。压力/软边不增加空开关。
