# 第二批：截图 / 导出

用户主任务：在画布上拖出区域，预览、复制或保存清晰 PNG；同时能明确选择当前视口和全部对象。

## 已定方向

比较“全程大弹窗内框选”和“画布上轻遮罩框选＋独立预览”，采用后者：保留上下文，接近 Windows 截图工具；使用原有主题字体、边框和操作色，图像预览优先，无额外装饰动画。先选范围/倍率，框选时简短提示与 Esc，生成后统一预览/重新框选/复制/保存。完整画布额外提供留白。

单一入口用于自由画布及关系画布；不改底层记录与引用结构。保留单 BoardClient 与第一批窗口机制。截图期间隔离普通平移、绘图、选择、缩放、历史快捷键，结束恢复。

## 渲染与边界

- 复用内容数据、笔迹 SVG 路径和关系曲线几何进行 Canvas 高清合成，读取 DOM 的主题/文字样式及便签滚动位置；不以屏幕低分辨率截图作为导出源。
- 修复正文颜色状态泄漏；保留现有卡片尺寸和层叠，不再自动展开长便签造成覆盖。按当前卡片可见正文导出，全文仍在原记录中。
- 三种范围共用同一渲染器和 PNG 结果；预览、复制与下载使用同一 Blob。视口/区域按 CSS 逻辑像素乘 1/2/4；全部对象按世界坐标，留白独立设置，不乘 Windows DPR。
- 包含所有自由便签、形状/笔迹、图片/文件卡片；关系节点与连接保持语义颜色，标签纳入全图边界。缺失原图明确失败，低分辨率素材如实提示。
- 编码前检查 16384px 单边/3200万像素上限。剪贴板使用窄 IPC、PNG 字节与像素校验，浏览器使用标准 Clipboard API。

## 实施和验收

1. 增补导出尺寸、框选坐标与剪贴板校验的必要单测。
2. 统一数据合成器，保留实际叠层；为两类画布接入一致 source/request 接口。
3. 改造 ExportDialog 为模式选择/框选/预览，统一主入口、通知、清理和焦点恢复。
4. Windows Electron：实际框选、Esc、重选、复制/保存、全部层像素/边界、1/2/4倍与DPI、超限与缺图错误，确认记录/历史/相机不变。
5. 亮暗1440/820/390截图，两轮视觉检查，运行相关旧回归。更新报告与HANDOFF后停止，不进入第三批，不默认打包/推送。
