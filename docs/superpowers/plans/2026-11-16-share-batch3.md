# 第三批：共享界面精修

面向桌面端向同局域网同事分享白板的用户，优先让用户看清是否共享、监听网卡和下一操作。保持 Graphite 主题、权限、协议、窗口生命周期及原始业务数据不变。

## 设计决定

- 比较三个方向：居中图标引导页（占位多），状态/网络/链接并列卡片（窄窗口拥挤），纵向工具面板（选用，沿用弹窗且阅读顺序明确）。
- 返回导航 → 设备网络图标＋标题/一句说明 → 独立共享状态 → 网卡选择/操作 → 地址/次级复制 → 访问范围。
- 沿用 Segoe UI/微软雅黑、既有亮暗 semantic tokens。标题18/26px、正文/辅助12/20px、状态13px；16–24px模块间距；状态颜色使用 success/warning/error，文字同时标明状态。
- 开启共享为唯一 primary；刷新、复制、停止和返回使用次级样式；按钮 hover/pressed/focus/disabled 沿用控件系统。仅120ms颜色过渡，减少动态为0，不新增窗口切换动画。

## 实施与验收

1. 提取共享展示组件，区分启动/停止/刷新操作；显示未开启/启动中/共享中/失败及具体原因、重试。服务仍运行的失败不得显示成已关闭。
2. 替换语义不明广播图标，统一工具区及复制地址；保留无网卡、地址失效、启动/停止失败和访问权限说明。
3. 实际 Windows Electron 验证亮暗1440/820/390、键盘/焦点/减少动态、启动等待/失败重试/停止失败/刷新与复制；验证关闭、Esc、返回和速记切换不重建原画布。
4. 两轮截图复查，运行构建、单测、共享网络回归及窗口生命周期回归。生成报告、原生截图和交接，第三批完成后停止，不自动打包或推送。
