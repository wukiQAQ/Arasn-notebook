# 便签角色与基础控件第一批

**目标**：同一正文在主编辑区、关系摘要节点、自由空间对象中具有清楚的展示角色；完善设置复选框和选择菜单。
**技术**：沿用React/TypeScript、现有CSS tokens与Base UI，不增加依赖或存储迁移。

## 审查与展示模型

| 场景 | 数据来源 | 展示责任 | 本批处理 |
|---|---|---|---|
| 便签页 | RecordSession + text/node原记录 | 搜索、最近、正文、保存、记录管理 | 文档页眉、限制阅读宽度的大正文、保存页脚、关联筛选与文件管理入口 |
| 关系节点 | canvas-node.contentRef + layout | 类型/状态、标题、两行摘要、真实保存状态、连接 | 紧凑信息卡，保留已存尺寸/锚点；完整正文仍通过属性面板或打开原记录编辑 |
| 工作页便签 | 同一text记录 + x/y/width/height | 空间摆放、短文本、绘图共存 | 纸片边角、细色签、显式拖动条，不加关系锚点、不改坐标或正文 |

现有问题：自由页与关系节点共享近似容器皮肤；正文页页眉直接重复第一行文字；原生select弹层不可统一；checkbox缺少统一状态。现有笔迹级橡皮擦已具备Undo/范围圈/大小/其他对象保护；第二批整理入口和行为，不重复实现。画笔仍只有颜色/粗细，第三批再扩展；StrokeValue暂无平滑度/端点/笔刷字段，届时需兼容旧数据。

## 设计方向

1. **选用：文档/关系卡/纸片**。用布局、信息密度与操作结构区分，适合现有数据模型，保留Graphite深色系统。
2. 同一容器加不同色条：改动少，但不足以区分主编辑与空间摘要，不选。
3. 三套独立彩色皮肤：区分大，但打散现有主题与控件语言，不选。

沿用Segoe UI/微软雅黑、背景#13161b、索引#1b2028、正文#252b36、浮层#303848、正文#f1f3f7、品牌#9aafff。字号12/14/16/22，间距4/8/12/16/24/32；复选框18px，选择框36px、圆角7px、2px键盘焦点。类型色点通过语义token同时适配亮色，配文字不单凭颜色识别。高频操作保持直接可见，无新增装饰动画。
