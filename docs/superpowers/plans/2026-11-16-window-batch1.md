# 第一批：窗口状态与共享关闭闪屏

用户：桌面速记与工作站用户。主任务：随手呼出速记，并准确回到此前工作位置。
约束：现有主题、单份业务数据和恢复队列、托盘策略与快捷键保持兼容；本批不做截图导出与共享视觉重排。

## 方向与决策

- 双原生窗口：几何天然独立，但目前 recovery 整包写入、IPC 信任窗口、输入钩子及退出握手都绑定单个 renderer。直接复制会有恢复数据互相覆盖的风险，留后续架构专项。
- 单窗口可见尺寸切换：不能消除用户看到的缩放跳动，不采用。
- **采用：单原生窗口，两套独立几何与 UI 会话，隐藏切换，提交后显示**。只共享一个 BoardClient；保持工作区挂载。

视觉沿用已有 tokens、字体、间距及亮暗主题。无新增切换动画。共享关闭保留原内容至退出完成，避免空值落入设置页分支。仅补必要的返回导航。

## 实施和验收

1. WindowManager 分开保存 Quick bounds 与 Workspace normal bounds / maximized，单测覆盖重启、最小化、拔屏和失败重试。
2. 窗口切换通过 generation IPC 确认目标 React 布局已提交；隐藏期间调整几何。过期确认无效，超时回滚。
3. 保持两个模式的 DOM 子树挂载，分开编辑选择/草稿/光标；不重置 workbenchPage。
4. 修复共享关闭分支，验证按钮、Esc、返回、模式切换；检查 DOM 身份和画布视口/选中项。
5. Windows Electron 实际运行、普通/最大化/隐藏恢复、亮暗截图、原有回归；记录限制后停止，不进入第二批。
