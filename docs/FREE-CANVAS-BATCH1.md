# 自由工作页第一批 · 2026-11-13—14

## 根因与设计
固定1600×1000纸面、scrollLeft/scrollTop平移、坐标截断与服务端非负校验共同限制空间。SVG笔迹与HTML便签使用世界坐标；现有SQLite/BoardClient自动保存和恢复队列不变。

用户是整理文字与草图的桌面用户，核心任务是连续记录、自由移动和找回内容。比较底部工具坞（占宽）、常驻属性栏（压缩画布）和左侧工具组（选用）；保留现有侧导航。左侧40px按钮按导航/绘图/内容分组，属性弹层，右下视图控制，精简页头。沿用Segoe UI/微软雅黑、现有深浅主题语义色与7px控件圆角、8/12/16间距；画布变换不做动画。

## 实施计划
- [x] 复用screenToWorld/zoomAt，允许自由页独立25%–400%，不改变关系画布默认范围。按room保存本机视口，失败提示。
- [x] 替换滚动纸面为裁剪视口、世界层和随视口更新的点阵；放宽便签/笔迹到正负100万坐标，保留旧格式无需迁移。
- [x] 拆分浮动工具与属性弹层、独立视图；选择空白/移动工具/无中键冲突时临时中键pan；取消与失焦清理。
- [x] 验证锚点缩放、跨边界绘画、旧数据不变、保存/重启、桌面/窄窗/DPI和关系回归。真实截图复查两轮。

## 兼容与边界
不清空/重写已有对象，不修改关系节点与文件实体。视口仅本机，按room隔离。世界范围±100万，避免无限浮点漂移。旧版本客户端不能可靠编辑新范围内容；共享端需使用同一新版。第一批不增强擦除/选择图形/Redo。导出最低限度按实际内容边界防止新坐标裁切，限制输出像素防止巨型位图。

- Node单测53/53通过，包含两个新增世界坐标/视口数学测试。

未进行混合DPI多屏、物理触控板/笔设备、全局中键物理触发、海量对象压力及保存失败故障注入；不把本机自动化鼠标测试等同于这些硬件测试。未运行安装向导、未重打包Portable/Setup，也未操作个人数据。浏览器Edge双客户端共享回归1/1通过：正文与笔迹同步、离线恢复、冲突保留、便签拖动、平移不新增笔迹及PNG下载。

验收过程的残留不确定性：Electron自动化首次拖动曾偶发未生效，最终隔离运行通过；测试已在模式切换后固定窗口尺寸并保留失败时的pointer/blur事件追踪，尚未确认是否仅为窗口焦点/自动化时序。第四批需用物理鼠标复核，不据最终一次通过宣称长稳。
