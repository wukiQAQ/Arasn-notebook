# 前端项目启动提示词（复制到 Codex）

请使用已安装的 frontend-design Skill 设计并实现以下页面，并在完成后使用 web-design-guidelines 与 visual-qa 做检查。

项目：〔填写产品／页面类型〕
目标用户：〔填写〕
最重要的用户动作：〔填写〕
页面必备内容：〔填写〕
技术栈：保持当前仓库的框架与组件约束；如果是空项目再建议技术方案。
设计参考：〔放截图路径、设计稿、URL；没有就填“无”〕
不希望出现的风格：通用蓝紫渐变、满屏圆角卡片、机械排列的图标矩阵；除非产品语境需要。

执行要求：
1. 先审查项目、内容与参考，提出 3 种有明显差异的视觉方向（每种包括布局、字体、配色、留白、图片策略），并说明各自适用场景；如果我没有要求选择，你自行选择最合适的一种并解释理由。
2. 在动手写页面前先列出设计 token（字体层级、颜色、间距、容器宽度、圆角、阴影、动画节奏）和核心版块的视觉结构。
3. 实现真实可用的界面，不能把静态展示冒充可交互功能，不得虚构真实数据。
4. 用真实浏览器渲染并截图：桌面约 1440px、手机约 390px；必要时加平板宽度。检查首屏焦点、字体、对齐、裁切、间距、交互和响应式。
5. 根据截图指出最明显的 5 个视觉问题，至少做 2 次针对性的修改和复查。截图看不到或无法运行浏览器时明确说明，不要虚构验收结果。
6. 输出结果包括：设计选择、改动文件、启动方法、截图或截图路径、已检查项与残留问题。

评价标准：信息层次清楚、设计有独特但合适的风格、适配移动端、可读性高、交互真正有效，且和最初的视觉方向一致。
