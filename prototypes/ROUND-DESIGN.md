# C 延展：圆润，但保留性格

用户已认可 C 的方向，要求继续探索圆润主题与不落模板的图标；本轮不再推荐改回 B，也未开始正式业务重构。

入口：`/round.html`，通过 `?concept=mellow`、`?concept=cove`、`?concept=afterglow` 直达。重新启动：根目录 `npm --prefix prototypes run dev`；本轮预览端口为 5178。

## 图标与组件

参考 [Iconoir 官方规范](https://iconoir.com/docs/faq) 的 24px 网格与轻量线条，主导航、品牌、投递、新建、搜索、呼出、叶片与说明等 11 个 glyph 在 `src/round/Icons.tsx` 中原创绘制：1.6px 圆头、开放轮廓、局部10%填色，不复制第三方图标资源。Iconoir 仅为参考，未安装依赖；文件/画布/命令面板的次级图标复用已安装的 Lucide。没有购买图标或引入整套通用组件模板。

形状按功能分层：包围工作空间的轮廓最圆，内容纸面较收敛，选中便签保留有辨识度的小角，控件保持明确点击区域。没有给每个控件套同一种卡片，也没有渐变或持续装饰动画。

## 可操作范围

便签增删改和拖柄拖动/方向键移动，画笔，平移/缩放，Ctrl/Cmd+K 命令与键盘导航，真实文件选择与拖入、分类搜索和预览，浏览器内收起/恢复，方案切换共享会话内容。新建、文件读入成功才显示操作反馈。单文件上限20MB；刷新重置，不写入正式存储、不共享到LAN，不注册系统热键。Office 只提供原文件下载，PDF/音频依赖浏览器能力。

Motion 仍为唯一动效库，复用现有画布和文件组件。拖动通过 MotionValue 跟手，不加指针滞后；命令使用共享高亮，收纳/呼出使用短位移和透明度，悬停投递图标微抬2px。支持系统减少动态效果，保留可见键盘焦点；说明与命令使用已有 Base UI Dialog 约束焦点。
