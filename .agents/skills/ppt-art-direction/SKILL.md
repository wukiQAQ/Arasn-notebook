# PPT Art Direction

## Story before slides
1. Establish audience, decision or learning goal, presentation length, source information and brand constraints.
2. Define the narrative arc; each slide should communicate one main takeaway, supported by the material.
3. Produce a storyboard: slide number, takeaway headline, evidence, visual archetype and any source or asset need.
4. Assign varied layouts intentionally: hero/statement, evidence chart, two-sided comparison, timeline, diagram, image story, or summary. Do not turn every slide into 'title + three bullets'.

## Visual system
- Default widescreen 16:9 unless the brief says otherwise.
- Build consistent margins, type hierarchy, palette, alignment grid and chart style. Treat these as starting choices, not arbitrary hard limits.
- Use images, diagrams and editable charts when they reveal meaning; avoid purely decorative clutter.
- Prioritize readable text and appropriate density for the actual presentation setting. For projected slides, prefer generous type sizing; dense appendix slides may differ.
- For Chinese presentations, verify Chinese-capable font availability and line breaks. Check fallback and unexpected font substitution.
- Never fabricate facts, data, dates, figures or citations.

## Export QA
- Keep .pptx editable when requested; preserve text and diagram editability where feasible.
- Render all pages, review a montage, inspect crowded pages individually, fix clipping/overlap/font substitutions, and re-render.
- If the environment cannot render, label the result 'not visually verified' rather than claiming it passed QA.
